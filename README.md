# Ayurveda Clinic Software

Clinic management software for multi-branch Ayurveda clinics, built with Claude Code.

**To start:** double-click `start.bat`. Read `docs/START_HERE_WINDOWS.md` first.

| File / folder | What it is |
|---|---|
| `docs/START_HERE_WINDOWS.md` | Install, start, stop, log in, demo users |
| `docs/HOW_IT_WORKS.md` | Plain-language explanation |
| `docs/FOLDER_MAP.md` | What every folder is for (SAFE TO EDIT / ASK FIRST) |
| `docs/SMALL_CHANGES.md` | Recipes for small changes |
| `docs/TROUBLESHOOTING.md` | Common problems and fixes |
| `docs/GLOSSARY.md` | Tech words explained |
| `docs/FEATURES.md` | The full feature list |
| `docs/BUILD_STEPS.md` | The build plan and the prompt for each step |
| `CHANGELOG.md` | What changed in each step |
| `CLAUDE.md` | The project brief that Claude Code reads. **Ask first** before editing. |
| `backend/` | Django API (Python) |
| `frontend/` | React screens (TypeScript) |
